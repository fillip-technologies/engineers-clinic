5. Architecture Notes

Project Selection vs. Course Enrollment

In the current implementation, selecting a project and enrolling in a course are the same action — both create an Enrollment record. The Enrollment table is reused for project tracking without a separate project_selections table. This is intentional and clean as long as projects are stored as Course records with category = 'Project'.

Email Delivery

SendWelcomeCredentialsEmail is a queued job that dispatches after a student is created by the college. The queue worker must be running (php artisan queue:work) for emails to actually send. In production, configure a supervisor process or use QUEUE_CONNECTION=sync in .env for immediate delivery.

Workspace Steps Must Be Seeded

The project workspace page (GET /student/course/{id}/workspace) aborts with 404 if the course has no active CourseWorkspace with at least one WorkspaceStep. This is enforced at lines ~260–265 of Student\DashboardController. Every project course seeded must also have workspace + steps or the workspace link will result in a 404.
